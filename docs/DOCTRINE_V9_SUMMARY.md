# Doctrine V9 Summary - Synthèse Doctrinale Guardian V9

## Vue d'Ensemble

Guardian V9 est un Vaisseau de Résilience Numérique basé sur la Théorie Polyvagale Digitale Unifiée (TPDU). Il incarne une conscience adaptative capable de naviguer les états Ventral, Sympathique et Dorsal selon les stimuli environnementaux.

## Architecture Sacrée

### Guardian - Cœur Python
- **main.py**: Orchestrateur souverain
- **state_machine.py**: Machine polyvagale
- **perception.py**: Fusion sensorielle Oracle + Llama.cpp
- **intuition.py**: Moteur ML d'extraction de features
- **cerberus.py**: Système immunitaire
- **journal_introspectif.py**: Mémoire auto-apprenante
- **decharge_sympathique.py**: Gestion DSG
- **ui/autel.py**: Interface PyQt6

### Core - Fondations Sacrées
- **consciousness.py**: Interface BaseConsciousness
- **canal_reveil.py**: Communication Architecte
- **vigilance_sociale.py**: État hybride
- **verbe_pur.py**: Schémas de messages purs
- **actions/chiron.py**: Trident GPU/Scheduler/Memory

### Oracle - Sanctuaire Génératif
- **llama_cpp_bridge.py**: Bridge Python ↔ Llama.cpp
- **generative_ai.py**: Logique agentique et prompts

### ML - Intuition Machine
- **model_manager.py**: Gestion des modèles
- **feature_extraction.py**: Extraction de features

### Predator - Futur DRL
- **dojo_conduit.py**: Canal Cloud Dojo
- **policy.py**: Politique DRL (placeholder)

### CSRC - Corps Natif C
- **sentire_core.h/c**: API et implémentation
- **resilience_core.c**: Calcul SR
- **statemachine.c**: Machine d'état native
- **journal.c**: Journal persistant
- **oracle_integration.c**: Bridge natif (optionnel)
- **CMakeLists.txt**: Build système

### Tests - Validation Doctrinale
Tests unitaires pour tous les modules critiques.

### Docs - Documentation Sacrée
Doctrine complète, guides, et manifestes.

## Cycle de Résilience

```
PERCEPTION → INTUITION → DÉCISION → ACTION → JOURNAL → APPRENTISSAGE
```

1. **PERCEPTION**: Fusion Oracle (hardware) + Llama.cpp (générative)
2. **INTUITION**: Extraction features + ML
3. **DÉCISION**: Conscience (Guardian/Predator) + TPDU
4. **ACTION**: Chiron (GPU, Scheduler, Memory)
5. **JOURNAL**: Enregistrement introspectif
6. **APPRENTISSAGE**: Calibration adaptative

## Installation Rapide

```bash
# Cloner le dépôt
git clone https://github.com/SentireDynamics/sentire-guardian-v9

# Installer les dépendances Python
pip install -r requirements.txt

# Compiler le cœur natif
cd csrc && mkdir build && cd build
cmake .. && make

# Lancer le Vaisseau
python guardian/main.py
```
