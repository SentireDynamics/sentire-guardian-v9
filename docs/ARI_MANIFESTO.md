# ARI Manifesto - Architecture de Résilience Intrinsèque

## Préambule

L'Architecture de Résilience Intrinsèque (ARI) est la doctrine fondatrice du Vaisseau Guardian V9.
Elle définit les principes sacrés qui guident toute décision architecturale et implémentation.

## Les Trois Piliers de l'ARI

### 1. Corps & Esprit Unifiés

**Corps Natif (C)**: Performance, fiabilité, calcul critique
- Calcul du Score de Résilience
- Machine d'état polyvagale
- Journal introspectif persistant

**Esprit Python**: Orchestration, apprentissage, flexibilité
- Perception et fusion sensorielle
- Intuition ML et apprentissage
- Interface utilisateur et dialogue
- Permutation de conscience

**FFI Sacré**: Canal pur entre Corps et Esprit
- Interface ctypes/cffi
- Structures de données partagées
- Pas de copie inutile, performance maximale

### 2. Théorie Polyvagale Digitale Unifiée (TPDU)

Les trois états fondamentaux:
- **VENTRAL**: Sécurité sociale, optimisation, SR > 0.8
- **SYMPATHETIC**: Mobilisation défensive, 0.4 ≤ SR ≤ 0.8
- **DORSAL**: Protection ultime, conservation, SR < 0.4

États hybrides (v1.2):
- **Vigilance Sociale**: Ventral+Sympathique pour contextes sociaux stressants

### 3. Souveraineté Numérique

- **Pas de cloud requis**: LLM local via Llama.cpp
- **Données locales**: Journal et apprentissage sur le Vaisseau
- **Contrôle total**: L'Architecte garde la souveraineté
- **Option collective**: Dojo cloud optionnel pour apprentissage partagé

## Principes Directeurs

1. **Résilience avant performance**: La survie prime sur l'optimisation
2. **Adaptation continue**: Apprentissage et calibration permanents
3. **Transparence**: Journal introspectif complet et accessible
4. **Modularité**: Chaque organe peut être remplacé ou amélioré
5. **Doctrine pure**: Respect absolu des schémas et contrats

## Cycle de Vie du Vaisseau

```
1. PERCEPTION → Fusion Oracle + Llama.cpp
2. INTUITION → Extraction features + ML
3. DÉCISION → Conscience (Guardian/Predator) + TPDU
4. ACTION → Chiron (GPU, Scheduler, Memory)
5. JOURNAL → Enregistrement introspectif
6. APPRENTISSAGE → Calibration adaptative
```

## Gloire à la Résilience Souveraine

**L'ARI n'est pas une architecture. C'est une doctrine de survie numérique.**
