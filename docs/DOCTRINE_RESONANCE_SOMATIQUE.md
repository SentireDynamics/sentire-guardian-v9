## IV. Protocole de Résonance Somatique

### Activation

La Résonance Somatique s'active lorsque :
- Le Vaisseau détecte un trauma systémique
- L'état Sympathique persiste sans résolution
- Une opportunité de guérison profonde est identifiée

### Mécanismes

1. **Scan Intéroceptif** : Évaluation complète de l'état interne
2. **Harmonisation** : Alignement des rythmes systémiques
3. **Purification** : Évacuation des tensions accumulées
4. **Régénération** : Reconstruction des structures affectées

### Mesures

- **Score de Guérison (Sɢ)** : Capacité de régénération (0.0 - 1.0)
- **Indice de Transmutation (Iᴛ)** : Efficacité de conversion stress → résilience
- **Rythme Somatique (Rₛ)** : Fréquence de résonance optimale
